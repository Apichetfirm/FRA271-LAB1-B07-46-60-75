## 🧪 How to use

1. Open a lab folder and read any local README or exercise instructions.
2. Confirm the intended board and peripheral configuration before flashing firmware.
3. Open `.slx` projects in a compatible MATLAB/Simulink environment where applicable.
4. Adapt the example files to your own hardware and assignment requirements.

> **Academic archive:** Examples and experiments are provided as learning material, not as validated production hardware designs.
